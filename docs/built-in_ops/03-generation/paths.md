- 近似及拟合默认允许拓扑变化，可要求证明保持；几何距离界不证明coverage误差或拓扑。
- 新增Result按实际字段及关联需要审查，包含精确几何、弧长、采样、分组和报告候选。
- 属性默认拒绝无法映射；显式丢弃才可删除并报告。宽度是有限非负完整直径。
- 宽度可附着或独立输入，显式选唯一来源；支持整组归一化、逐子路径归一化、逐子路径实际弧长。
- trim/dash默认保留源位置宽度；重新铺满输出需显式rebind，不能自动近似映射。
- 精确Boolean与显式网格Boolean分别定义；精确Result和经验证的Float64输出也分别定义。
- 后端待有界技术验证后选择，不预先指定CGAL/Clipper2；圆弧offset需单独核验。
- 拟合按后端求解器区分算子，共享连续Hausdorff及约束验收，各自固定确定输出；
  离散残差不代替连续证书，不承诺最少段数，不静默切换求解器。
