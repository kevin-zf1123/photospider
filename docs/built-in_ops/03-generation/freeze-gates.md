# Technical freeze gates

These are unresolved engineering details under the [accepted decisions](decisions.md),
not unanswered D01–D12 choices. No first implementation batch is selected.

| Area | Required output before registration/production |
| --- | --- |
| Member identity | Confirm candidate boundaries, exact versioned keys and backend/profile admission; preserve within-profile bits and retire superseded test interfaces with caller migration. |
| Execution | Per-member output/read/validation/dirty rules, ROI/halo correctness, budgets, cancellation and retained-result lifetime. GPU candidates must run through public workflows. |
| Color | Verify affected CRV/FMT migrations against straight, units, original hue and complete descriptions; candidate status is not runtime support. |
| Structured results | Review actual schemas, factories/codecs, count and snapshot associations, exact geometry representation and consumers; decide whether candidate reports share structures. |
| Width | Freeze key spelling, three parameter domains, source maps, zero length, closed seams, out-of-domain policy and explicit rebinding rules. |
| Approximation | Freeze deterministic algorithms and verify total geometric bounds, publication error and optional topology proof. Measure chosen 0.05/0.25 px settings. |
| RNG | Specify Philox4x64-10 packing/key injection, output bits, finite float grids, domain/draw allocation and candidate ordinals; replace obsolete draft vectors; independent known-answer and CPU/GPU bit tests. |
| Point sets | Freeze stop-reason schema, zero/upper count behavior and separately named safety budgets; verify candidate-prefix/FIFO sequencing and exact published-point distances. |
| Rank assets | Generic lookup needs structural tests; named blue/STBN additionally needs fixed asset identity, provenance/license and accepted quality reports. |
| Geometry backend | Bounded candidate evaluation for exact and grid variants: behavior, dependencies/license, precision, canonicalization, accounting, cancellation and publication. No backend is preselected. |
| Offset | Specify original offset boundary, circle/line constructions, approximation and publication; polygon rational arithmetic alone is insufficient. |
| Fitting | Select and freeze each solver-specific operator; validate continuous Hausdorff certificates, constraints, deterministic output and optional topology proofs. |

Focused implementation validation must use independent mathematical checks and
public WorkflowDocument/compiler/execution paths as applicable. Do not substitute
archive Python self-tests for revised runtime coverage. Select implementation
batches after these dependencies are understood; unresolved gates can delimit
batches without undoing accepted design scope.
