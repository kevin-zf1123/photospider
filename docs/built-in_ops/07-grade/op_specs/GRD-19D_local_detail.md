# GRD-19D: Independent local detail strength

Inherits the [family contract](GRD-19_shadow_highlight_local_contract.md) and [GRD common contract](GRD_common_contract.md). The proposed tile operation `grade.local_detail` performs the transformation below.

## Interface

`input: T[H,W,C]`, `detail_gain: Float64[1]` -> `values: T[H,W,C]`.

Relative linear RGB/Gray. Base parameters are as GRD-19A; detail_gain>=0, suggested 1.

Port ordering, tensor members, calculation dtype, channel selection, static parameter types and unchecked premises follow the common contract. Output shape and dtype are those in the signature.

### Static parameters

`axis`, `components`, `input_description`, `group` and `max_work` follow GRD-19B. `radius`, `sigma_space`, `sigma_range` and `epsilon` follow GRD-19A. String `source_basis` and RGB/Gray basis selection follow GRD-19C. Detail gain is a dynamic Float64 tensor.

## Mathematics

Extract Y, z and base b at the Float64 boundaries in GRD-19C. Return x*exp2((detail_gain-1)*(z-b)). gain=1 copies; gain=0 removes log detail; gain>1 enhances it.

### Current native algorithm/profile

Use the GRD-19C Float64 luminance and log stages and the GRD-19A centered bilateral mean. Compute only `e=(detail_gain-1)*(z-base)`, then apply the GRD-19B native gain and single conversion to T. Gain one copies the source; a constant published log neighborhood, including equal infinities generated by RGB luminance overflow, has exactly zero detail and copies the selected source bits for every finite gain. Radius zero copies for any finite gain because the published base equals z. Alpha and unselected components copy independently.

## Behavior

H(radius), with source colors at the output coordinate. Alpha/AOVs copy their source bits; bypass-only dependencies have the execution-tile scope specified in the family contract.

## Acceptance

Constant Y is unchanged for every gain. Gain one is bit-preserving identity. Check a bright point with a nonzero neighborhood radius. When all non-center spatial exponents are negative infinity, an overflowing RGB luminance must not contaminate neighboring finite pixels through zero-weight arithmetic. Relative linear-Y Gray descriptions accept `relative_luminance`.

Apply the common native-versus-strict comparison rules and compare ROI/tile observations at identical global coordinates. Reference equations and source attribution are in the family contract and [research sources](../research-sources.md).
