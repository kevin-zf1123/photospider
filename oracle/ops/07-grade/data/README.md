# CIE observer data

`CIE_xyz_1931_2deg.csv` is an unchanged copy of the CIE 2019 dataset *Colour-matching functions of CIE 1931 standard colorimetric observer*, published by the International Commission on Illumination (CIE), Vienna, Austria.

- Dataset DOI: [10.25039/CIE.DS.xvudnb9b](https://doi.org/10.25039/CIE.DS.xvudnb9b).
- Original data: [CIE CSV](https://files.cie.co.at/Publications-datasets/CIE_xyz_1931_2deg.csv).
- Original metadata and license declaration: [CIE metadata](https://files.cie.co.at/Publications-datasets/CIE_xyz_1931_2deg.csv_metadata.json).
- License: [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).

The four columns are wavelength in nm and the CIE 1931 2-degree x-bar, y-bar and z-bar functions. The 471 rows cover 360 through 830 nm at 1 nm intervals. The GRD temperature/tint oracle uses the published decimal coefficients as exact reference constants. This data license applies to the CSV; it does not change the license of the independent Python reference code.
